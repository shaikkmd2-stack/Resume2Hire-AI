## Brand & Style

This design system embodies a modern, data-driven, and high-efficiency intelligence hub for AI-accelerated talent acquisition and professional career matching. The brand bridges two high-stakes audiences: discerning corporate recruiters seeking decisive signal over noise, and ambitious candidates demanding seamless, high-confidence career advancement.

The emotional signature is clean, authoritative, and frictionless. The aesthetic avoids all ornamental excess, playful gimmicks, or historic motifs, relying instead on razor-sharp typography, deliberate architectural hierarchy, deep navy contrast, and high-velocity digital polish.

The design movement combines **Modern Corporate Precision** with **Atmospheric AI Nuance**:
- **Pristine Canvas Architecture:** Stark, clean white foundation elevated by structural border grids and ultra-crisp slate typography.
- **Controlled Luminescence:** Restrained, synthetic indigo-to-violet linear accents that signify active AI evaluation, dynamic matching, and real-time computation without distracting from data density.
- **Operational Clarity:** High-density data metrics, clean information hierarchies, and responsive micro-elevations engineered for sustained scanning and executive decision-making.

## Colors

The color palette centers on maximum optical contrast, strict hierarchy, and deliberate energetic cues.

### Brand & Intelligence Anchors
- **Primary Indigo (`#4f46e5`):** The functional core. Drives primary interactive targets, navigation accents, and confirmed actions.
- **Secondary Violet (`#8b5cf6`):** The computational AI accent. Applied alongside the primary indigo to form directional subtle gradients (`135deg, #4f46e5 0%, #8b5cf6 100%`) for AI resume scorecards, algorithmic match badges, and premium operational highlights.
- **Tertiary Teal (`#06b6d4`):** An analytical telemetry accent for candidate readiness scores, telemetry charts, and high-confidence metrics.

### Neutral Slate Foundations
- **Navy Deep / Ink 950 (`#0f172a`):** Primary display headers, dominant figures, and brand anchor points. Replaces pure black to retain warmth and legibility.
- **Slate Text / Ink 800 (`#1e293b`):** Subheadings, critical body copy, input values, and table cells.
- **Muted Slate / Ink 500 (`#64748b`):** Metadata, descriptive subtext, secondary table headers, and dormant icons.
- **Border Default (`#e2e8f0`):** Precise 1px structural hairline divisions for cards, datagrids, and sidebars.
- **Border Subtle (`#f1f5f9`):** Inset table rows and secondary card sections.
- **Canvas Base (`#ffffff`):** Dominant surface canvas ensuring clinical focus and optical brightness.
- **Canvas Subsurface (`#f8fafc`):** App shell wrappers, inactive table stripes, and utility sidebars.

### State & Feedback Values
- **Success (`#10b981`):** Offer extended, candidate qualified, high match rate (>= 90%).
- **Warning (`#f59e0b`):** Pending review, incomplete profile, mid-tier score (65-89%).
- **Critical (`#ef4444`):** Candidate archived, parsing error, low relevance threshold (< 65%).

## Typography

Typography establishes functional hierarchy between high-level executive conclusions and dense data visualization.

- **Headlines (`Plus Jakarta Sans`):** Leveraged for executive titles, dashboard page summaries, candidate full names, and macro metrics. Its geometric structure provides energy, forward momentum, and modern authority without looking playful.
- **Body & Controls (`Inter`):** Engineered for dense tabular rows, candidate resume extracts, match feedback paragraphs, and form fields. It provides neutral, fatigue-free clarity during prolonged viewing sessions.
- **Telemetry & Scores (`JetBrains Mono`):** Reserved for technical skills tags, salary ranges, AI candidate match percentages, timestamp telemetry, and API status codes.

### Hierarchy Guidelines
- Always render high-level score outcomes (e.g., `98.4% Match`) using `title-card` or `headline-sm` with tight tracking.
- Apply `uppercase` treatment exclusively to `label-sm` when used inside system badges, pipeline status chips, or datatable header columns.

## Layout & Spacing

The layout philosophy uses a disciplined **12-column responsive fluid grid** with fixed outer constraints for dashboard density and candidate pipeline review.

### Breakpoints & Layout Architecture
- **Desktop (>= 1280px):** 12-column grid. Standard canvas max-width capped at `1440px`. Features a dual-pane setup: a persistent `260px` collapsed/expandable navigation sidebar paired with a flexible high-density workspace. Gutters sit at `1.5rem` (`24px`), margins at `2rem` (`32px`).
- **Tablet (768px - 1279px):** 8-column layout. Sidebar collapses into an icon rail or slide-out drawer. Dashboard metrics reflow to a 2x2 matrix. Gutters reduce to `1rem` (`16px`), margins to `1.5rem` (`24px`).
- **Mobile (< 768px):** 4-column single-flow layout. Recruiter candidate boards transition from multi-column kanban boards to segmented swipeable stage tabs. Margins tighten to `1rem` (`16px`).

### Spacing Principles
- Standard UI increments follow an strict 4px/8px rhythm.
- Metric cards use `space-md` (`16px`) internal padding to sustain high data density.
- Section splits across broad dashboard areas use `space-xl` (`40px`) to prevent visual clutter between candidate sourcing, parsing pipelines, and communication panels.

## Elevation & Depth

Visual hierarchy uses a refined hybrid of **flat crisp hairline borders** and **focused ambient shadows**. The system avoids heavy drop shadows, instead using edge contrast and luminous hover depth.

### Layering Model
1. **Base Foundation (Level 0):** Canvas background (`#f8fafc`). Completely flat.
2. **Surface Containers (Level 1):** Workspace cards, datatables, pipeline boards (`#ffffff`). Bordered with a sharp `1px solid #e2e8f0`. Elevated by an ambient shadow: `0 1px 3px 0 rgba(15, 23, 42, 0.04), 0 1px 2px -1px rgba(15, 23, 42, 0.02)`.
3. **Elevated & Interactive (Level 2):** Hovered candidate cards, active filter menus, and docked toolbars. Border transitions to `#cbd5e1` with depth: `0 4px 6px -1px rgba(15, 23, 42, 0.07), 0 2px 4px -2px rgba(15, 23, 42, 0.04)`.
4. **Floating Overlays & Drawers (Level 3):** Candidate detail drawers, interview scheduling modals, and floating AI prompt bars. Bordered with `#e2e8f0` and an elevated shadow: `0 20px 25px -5px rgba(15, 23, 42, 0.1), 0 8px 10px -6px rgba(15, 23, 42, 0.04)`.

### Computational AI Glow
When an element surfaces AI-generated insights, resume matches, or automated job descriptions, elevation is accompanied by a 1px pseudo-border gradient:
- Border fill: `linear-gradient(135deg, rgba(99, 102, 241, 0.4), rgba(139, 92, 246, 0.2))`
- Ambient back-glow: `0 0 20px -3px rgba(99, 102, 241, 0.12)`.

## Shapes

The design system maintains a refined balance between structured corporate architecture and modern SaaS ergonomics using `roundedness: 2`.

- **Standard Elements (`0.5rem` / `8px`):** Used on all standard controls, input fields, dropdown triggers, and buttons. Offers clean geometry without visual sharpness.
- **Large Containers (`1rem` / `16px`):** Metric summary cards, candidate pipeline columns, modal windows, and resume document previews.
- **Extra-Large Overlays (`1.5rem` / `24px`):** Onboarding dialogs and prominent marketing conversion panels.
- **Badges & Status Tags (`9999px` / Full Pill):** Applied exclusively to status indicators (e.g., "Screening", "Interview Scheduled"), match score tags, and parsed skill badges to differentiate them from actionable rectangular buttons.
